# Engineering Case Studies

This directory contains educational case studies extracted from real development work.

A case study should preserve the actual engineering path rather than present a fictional perfect solution.

## Recommended flow

```text
Problem
  -> Discovery
  -> Investigation
  -> Root Cause
  -> Alternatives
  -> Decision
  -> Implementation
  -> Code Review
  -> Review Fixes
  -> Tests
  -> Result
  -> Lesson
```

## Naming

```text
EDU-024-short-description.md
```

Create a case study when the task teaches a reusable engineering concept such as debugging, architecture, testing, concurrency, security, API design, or refactoring.
