# Шаг 1. Создание проекта

Открой терминал ВНЕ папки Amazone_Clone (на уровень выше):

```bash
cd I:\NewPythonProjects
npm create vite@latest frontend -- --template react-ts
```

Это создаст папку `frontend` с минимальным React + TypeScript проектом.

Перейди в неё:

```bash
cd frontend
```

Проверь что всё работает:

```bash
npm run dev
```

Открой http://localhost:5173 — увидишь страницу Vite + React.

Останови сервер (Ctrl+C).
